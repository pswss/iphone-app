**프로모션 텍스트 (170자):**

**설명:**
> 오늘(Oneul)은 하루를 한눈에 보는 타임라인 일정 앱입니다.
>
> ■ 말하거나 붙여넣으면 일정이 됩니다
> "내일 오후 3시 치과", "다음 주 월요일 9시 회의"처럼 평소 말투로 입력하세요. 시간표 전체를 복사해 붙여넣어도 한 번에 등록됩니다.
>
> ■ 개인정보는 기기 밖으로 나가지 않습니다
> 자연어 해석은 Apple Intelligence 온디바이스 모델로 처리됩니다. 입력한 일정 내용이 외부 서버로 전송되지 않습니다.
>
> ■ 하루가 무지개 바 하나로
> 오늘의 일정이 색색의 타임라인 바로 정리됩니다. 잠금화면과 다이나믹 아일랜드의 라이브 액티비티, 홈 화면 위젯, Apple Watch에서도 같은 바를 볼 수 있습니다.
>
> ■ 학교 시간표 자동 등록
> 학교·학년·반만 고르면 시간표가 자동으로 들어옵니다. 선택과목도 내 수업만 골라 담을 수 있고, 학사일정도 함께 가져옵니다.
>
> ■ 이런 것도 됩니다
> - 애플 캘린더 일정 가져오기
> - iCloud로 모든 기기 자동 동기화
> - 반복 일정, 색상·모양 꾸미기
> - 음성 입력(마이크)으로 손 안 대고 등록

## 5. 앱 개인정보 (App Privacy)

데이터 수집: **"예"** → 아래 한 항목만.

| 데이터 | 용도 | 사용자 연결 | 추적 |
|---|---|---|---|
| 식별자 → 기기 ID (푸시 토큰) | 앱 기능 | 아니오 | 아니오 |

근거:
- 푸시 서버(oneul-push)가 APNs 기기 토큰을 저장 → "수집"에 해당.
- 일정 데이터는 CloudKit **비공개 DB** → 개발자 접근 불가 = 수집 아님.
- NEIS 프록시는 조회 중계만 하고 저장 안 함 = 수집 아님.
- 마이크·음성인식·위치·캘린더는 전부 온디바이스 처리 = 수집 아님.

1. 버전 페이지 하단 "빌드" → TestFlight에 올라간 최신 Xcode Cloud 빌드(1.0 (1)) 선택.
