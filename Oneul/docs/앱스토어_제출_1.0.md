## 5. 앱 개인정보 (App Privacy)

데이터 수집: **"예"** → 아래 두 항목.

| 데이터 | 용도 | 사용자 연결 | 추적 |
|---|---|---|---|
| 식별자 → 기기 ID (임의 앱 기기 ID·APNs 토큰) | 앱 기능 | 예—기기 단위 | 아니오 |
| 사용자 콘텐츠 → 기타 사용자 콘텐츠 (당일 표시용 일정 제목·시각·상태) | 앱 기능 | 예—기기 ID와 함께 저장 | 아니오 |

근거:
- 푸시 서버(oneul-push)가 기기 ID, APNs 토큰, 당일 표시용 일정을 최대 3일간 저장 → "수집"에 해당.
- Apple은 기기 정보로 연결된 데이터도 "사용자와 연결"로 분류하므로 두 항목을 기기 단위로 연결된 데이터로 신고.
- 일정 데이터는 CloudKit **비공개 DB** → 개발자 접근 불가 = 수집 아님.
- NEIS 프록시의 실제 로그·저장 설정을 배포 전 확인. 즉시 중계 후 폐기한다면 Apple 기준상 별도 수집 신고 대상이 아님.
- 마이크·음성 인식은 Apple 정책이 적용되고, 위치는 Apple 지도에 장소명 조회를 요청한다. Oneul 서버는 이 데이터를 저장하지 않음.

Apple 공식 기준: https://developer.apple.com/app-store/app-privacy-details/

> 제출 전 필수: `Oneul/PrivacyInfo.xcprivacy`의 수집 데이터 항목과 인앱 개인정보 문구를 위 내용과 일치시킨다.
